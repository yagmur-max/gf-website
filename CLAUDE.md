# GF-WEBSITE — Golfery web sitesi

**Proje klasörü:** `~/Desktop/2-GOLFERY/GF-WEBSITE` · **Workspace:** `GF-WEBSITE.code-workspace`

Statik HTML sitesi: `index.html`, destinasyon sayfaları (`destination-*.html`), otel sayfaları (`hotel-*.html`), `hotels.html`, `golf-clubs.html`, `deals.html` vb.
Sayfalar birbirine **göreli link** verir — dosyalar bu klasörden dışarı taşınmamalı, yeniden adlandırılmamalı.

Tasarım kaynakları (`GF-Website.ai`, `GF-Website_Klasör`) aynı klasörde durur; Illustrator paketi (Fonts + Links + Rapor.txt + .ai) bütün halinde kalır.
